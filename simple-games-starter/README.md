# Simple Games

A customizable GitHub Pages starter with one game: Drift Hunters.

## Customize it

Open `styles.css` and change the colors at the very top under `:root`.

## Publish on GitHub Pages

1. Upload `index.html`, `drift-hunters.html`, `styles.css`, and the `assets` folder to the root of your `simple-games` repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

GitHub will show the public website address after deployment finishes.
